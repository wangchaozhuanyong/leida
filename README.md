# 模钥重置雷达

用于微信云托管内测的网站与 API 部署代码，包含当前黑金网站界面、公开公告归档和采集处理程序。

这是部署候选代码。上传 GitHub 不代表云托管已发布、数据库已接通或小程序体验版已上传。本仓库不包含原生小程序包、本机业务数据、密钥、数据库备份或验收日志。

## 云托管选择代码

| 配置 | 值 |
| --- | --- |
| 仓库 | `wangchaozhuanyong/leida` |
| 分支 | `main` |
| 构建目录 | 仓库根目录 |
| Dockerfile | `Dockerfile` |
| 服务端口 | `80` |
| 启动方式 | 使用镜像默认启动命令 |

`Dockerfile` 已适配云托管：监听 `0.0.0.0:80`，以非 root 用户运行，不使用本机 Docker Compose 专用的数据库地址改写。

## 发布前仍需完成

1. 准备可从云托管访问的 PostgreSQL 数据库。现有程序不能直接使用 MySQL。
2. 在服务的私有环境变量设置中填写 `.env.example` 中列出的实际值。不要上传 `.env`、密码或密钥。
3. `BETTER_AUTH_URL` 使用实际 HTTPS 服务域名；`BETTER_AUTH_SECRET` 使用独立随机密钥；`ENCRYPTION_KEY` 使用 32 字节随机值的 Base64 编码。
4. 核对并执行已有业务、登录及预告数据库初始化流程，先完成站长账号设置，再向外开放后台。不要直接运行 `bootstrap` 导入旧历史数据；该脚本包含 `seed` 步骤。
5. 数据库就绪后验证 `/api/v1/version` 与 `/api/v1/bootstrap`。首页能打开不能替代数据接口验证。

默认镜像只启动网站/API。采集 worker 尚需单独配置常驻运行；网站服务缩容到 0 不能保证持续采集。该项需要在实际云资源确定后核验。

## 已完成的本地验证

- 本部署候选 Docker 构建通过。
- 容器以 `node` 用户运行，端口 `80`，本机首页返回 HTTP 200。
- 未配置数据库时，数据接口返回 HTTP 500；因此当前尚未证明线上数据功能可用。
- 上传前核对部署包文件摘要与当前源码，运行代码一致。此仓库额外提供本文档、忽略规则和明确的环境变量占位值。

## 技术栈

Next.js 16、React 19、TypeScript、PostgreSQL；包管理器为 `pnpm@9.15.9`。

仓库面向容器部署。浏览器端不保存服务端密钥；真实微信发送、真机联网与小时级准确度需各自取得实际运行证据。
