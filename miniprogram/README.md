# 模钥重置雷达 · 原生微信小程序

本目录是独立原生客户端，不包含后台、采集任务、数据库或管理员登录。没有新增框架和依赖。默认未配置接口，页面显示“尚未连接”，不会使用样例冒充真实消息。

## 页面与数据

首页仪表、动态、重置公告、近26周日程、发布版本详情、活动每日进展、站内提醒、设置、判断说明和隐私说明均已提供。2026-10-13 按当前网站同步黑金仪表设计：原生四栏导航、统一顶部标题、24小时北京时间表盘、微信提醒下方的分享区，以及保持宽度稳定的详情展开。主要触控区域至少44像素。

表盘优先呈现已有公开预告的时刻，预计时间到期仍等待公开确认。没有当前预告时，最近公开完成公告显示小时和分钟，原文时间起算24小时后恢复等待预告；刷新不重开期限，切到后台停止计时、回来后续算。用量重置和重置卡各自保留最近完成记录，完整年份与北京时间位于标题下一行右侧。“确认”以核验后的公开完成声明为依据，个人账户到账未测得。

海报提供黑金与水墨配色切换，完整真码放入圆形白底，保留所有码点。原生海报采用本机完整公告排版，不把网站概念海报当作已还原结果。

2026-10-14 公开接口已填写现有微信云托管环境与服务，并在微信开发者工具 Stable 2.02.2608080、基础库 3.17.3 实际通过云调用加载线上首页。配置只包含公开标识，不使用默认公网测试域名作为生产 baseUrl。此前隔离快照仅在项目 QA 目录，不进入当前客户端。开发版本上传、设为体验版、真实扫码/订阅/相册权限验收分别记录，不能由模拟器联网成功推定已通过。

公开资料读取现有公共接口，无需读者登录：

- `GET /api/v1/bootstrap`：已发布快照、公开原文、活动、提醒和来源状态。
- `GET /api/v1/version`：前台检查版本，携带 `If-None-Match`，无变化不重复加载全部资料。
- `GET /api/v1/wechat/scene/{scene}`：将32位场景标识解析为固定发布版本，不按事件猜测最新版本。
- `GET /api/v1/wechat/code/{publicationId}`：按固定版本获取服务端生成的真实小程序码；未配置或不可分享时显示具体原因。

默认前台每5秒检查一次，返回前台立即读取；切到后台后停止检查并忽略迟到响应。断网保留本次打开期间最近资料，显示重试入口。没有后台常驻轮询、公开注册或管理员接口调用。微信提醒的独立读者身份仅在用户主动连接时建立，不用于公开资料读取。

福利动作只来自发布快照。仅新闻收录不改变福利状态，预计时间到期保持“等待确认”；定向和私人动作不计入普发日程。撤回内容仍可追溯，但不作为当前状态依据。正文更改、补录和刷新不创建提醒。站内偏好与已读记录只保存在本机。

## 两种连接方式

选择 `mode: 'https'`：`baseUrl` 填已上线公共接口的真实 HTTPS origin，不带 `/api/v1`、查询参数或路径。在微信公众平台配置对应请求合法域名，按实际环境满足备案、证书和网络要求。小程序正式运行不支持本机 HTTP 地址；`127.0.0.1` 也不是手机可访问的项目地址。

选择 `mode: 'cloud'`：填写实际 `cloudEnv` 和 `serviceName`。客户端用 `wx.cloud.callContainer` 调用同一接口，服务端仍需提供本项目 `/api/v1` 公共接口与 `/api/wechat` 读者接口。当前 `config.js` 已连接环境 `prod-d5gatkqvs39259932`、服务 `express-l98p`；2026-10-14 公网接口及开发工具内真实云调用已通过。该标识属于云托管服务；后端使用的免费 CloudBase 数据库环境是另一个后端配置，不能替换小程序里的云托管环境ID。

**云托管免自购域名，仅覆盖小程序公共接口的云调用。** 现有管理后台和正式网站仍需可信 HTTPS 入口及适配 Better Auth 的 origin；PostgreSQL 和常驻任务服务还需要独立、持久的运行资源。云托管默认公网测试域名不能当正式网站或生产 `baseUrl`。费用与额度由实际账户、套餐及资源用量决定，不承诺永久免费，也不默认要求把现有数据库或任务改成另一种产品。

微信官方文档：[网络请求](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/network.html)、[云托管域名](https://developers.weixin.qq.com/miniprogram/dev/wxcloudservice/wxcloudrun/src/guide/domain/)、[云托管调用](https://developers.weixin.qq.com/miniprogram/dev/wxcloudservice/wxcloudrun/src/development/call/)。

## 分享和提醒边界

原生朋友分享已提供，公告详情路径固定携带 `publicationId`，后续更正不会悄悄替换已分享版本。详情会提示已有新版本、撤回或事件合并；撤回和合并记录关闭该条公告的分享按钮。来源链接只能由用户点击后复制，不打开任意网页。

真实小程序码、场景解析与订阅的客户端和服务端代码已接通，默认关闭。仍需真实 AppID、AppSecret、微信公众平台可用模板、可信服务入口与调用上限。管理配置入口为 `/admin/settings/wechat`；AppSecret 只在服务端加密保存，不放入本目录。未配置时服务端返回“尚未配置”，不会调用真实微信接口或生成装饰替代码。

详情页用原生 Canvas 根据固定发布快照与对应真实码生成 PNG。码的圆形图案由微信接口提供，画布保留完整原图，不裁切或伪造。撤回、合并或缺失版本停止生成；场景和朋友分享均绑定同一 `publicationId`。图片只写入微信本机沙盒。用户点击“保存海报到相册”后才调用保存接口，按微信要求获得隐私同意与相册写入授权；不读取相册，不自动保存。当前尚未实际调用微信生成码、原生画布导出和真机相册接口。

设置页先点击“开启微信提醒”连接读者身份并准备模板，再点击“选择接收下一次提醒”主动弹出微信授权。一份普通订阅选择最多用于一次提醒，客户端只记录选择，实际发送以微信结果为准；不承诺永久订阅或送达。发送结果未知时显示待核，不自动再授权或重发。关闭后取消尚未发送的记录，已提交微信的请求无法召回，可能仍会收到。

`wx.login` 只由用户主动连接或管理提醒触发。读者会话仅保存在当前应用内存，失效或冷启动后需再次点击连接；不写本机存储、链接、日志或公共接口请求。公开 GET 请求与私有读者 Bearer 严格分开。服务端接口包括登录、状态、挑战、确认与主动撤销；当前仅通过本地受控输入验证行为，未证明真实微信登录、授权或送达。
