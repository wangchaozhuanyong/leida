选择 `mode: 'https'`：`baseUrl` 填已上线公共接口的真实 HTTPS origin，不带 `/api/v1`、查询参数或路径。在微信公众平台配置对应请求合法域名，按实际环境满足备案、证书和网络要求。小程序正式运行不支持本机 HTTP 地址；`127.0.0.1` 也不是手机可访问的项目地址。

选择 `mode: 'cloud'`：填写实际 `cloudEnv` 和 `serviceName`。客户端用 `wx.cloud.callContainer` 调用同一接口，服务端仍需提供本项目 `/api/v1` 公共接口与 `/api/wechat` 读者接口。当前 `config.js` 已连接环境 `prod-d5gatkqvs39259932`、服务 `express-l98p`；2026-10-14 公网接口及开发工具内真实云调用已通过。该标识属于云托管服务；后端使用的免费 CloudBase 数据库环境是另一个后端配置，不能替换小程序里的云托管环境ID。

**云托管免自购域名，仅覆盖小程序公共接口的云调用。** 现有管理后台和正式网站仍需可信 HTTPS 入口及适配 Better Auth 的 origin；PostgreSQL 和常驻任务服务还需要独立、持久的运行资源。云托管默认公网测试域名不能当正式网站或生产 `baseUrl`。费用与额度由实际账户、套餐及资源用量决定，不承诺永久免费，也不默认要求把现有数据库或任务改成另一种产品。

## 分享和提醒边界

原生朋友分享已提供，公告详情路径固定携带 `publicationId`，后续更正不会悄悄替换已分享版本。详情会提示已有新版本、撤回或事件合并；撤回和合并记录关闭该条公告的分享按钮。来源链接只能由用户点击后复制，不打开任意网页。

真实小程序码、场景解析与订阅的客户端和服务端代码已接通，默认关闭。仍需真实 AppID、AppSecret、微信公众平台可用模板、可信服务入口与调用上限。管理配置入口为 `/admin/settings/wechat`；AppSecret 只在服务端加密保存，不放入本目录。未配置时服务端返回“尚未配置”，不会调用真实微信接口或生成装饰替代码。

详情页用原生 Canvas 根据固定发布快照与对应真实码生成 PNG。码的圆形图案由微信接口提供，画布保留完整原图，不裁切或伪造。撤回、合并或缺失版本停止生成；场景和朋友分享均绑定同一 `publicationId`。图片只写入微信本机沙盒。用户点击“保存海报到相册”后才调用保存接口，按微信要求获得隐私同意与相册写入授权；不读取相册，不自动保存。当前尚未实际调用微信生成码、原生画布导出和真机相册接口。

进入提醒页直接读取已有次数并预备本次授权，无需“查看我的提醒”或“确认开启提醒”。预备完成后，用户点击“开启微信提醒 / 增加一次提醒”，在本次点击内同步调用微信授权；成功后只准备下一次请求，不自行弹窗或增加次数。每次主动点击并成功同意接收，增加一次机会；三次独立成功选择对应三次机会，分别用于之后不同的新预告、完成声明或重要更正。数量是本站记录，不冒充微信侧实时余额或送达保证。确认响应丢失后，用户可重试同一个 nonce，不重复弹微信或加次数。提醒页可见时每五分钟同步状态，在 nonce 过期前30秒预备下一次，短时间切回页面复用有效准备；离开页面停止定时准备。

发送结果未知时暂停后续发送及追加，不自动再授权或重发。关闭会清空本站剩余机会并取消尚未发送的记录；已提交微信的请求无法召回，可能仍会收到。本次客户端版本为 1.0.14（银白神经网络皮肤、分享入口与固定公告海报排版、提醒直接管理及关闭状态保留）。发布时先部署支持次数账本的后端并确认旧 worker 实例退出，再设新版为体验版；旧后端不能提供累计次数，客户端不会把准备请求当作新增授权。客户端减耗需要上传此版本，单独部署后端不会替换手机代码。

`wx.login` 在进入提醒页或主动管理提醒时按需触发，先检查隐私授权；隐私未同意时停止连接，用户同意后只加载状态，不自动订阅。首页及其他公开页面不会连接读者会话。读者会话仅保存在当前应用内存，失效或冷启动后在进入提醒页时恢复；不写本机存储、链接、日志或公共接口请求。公开 GET 请求与私有读者 Bearer 严格分开。服务端接口包括登录、状态、挑战、确认与主动撤销；当前仅通过本地受控输入验证行为，未证明真实微信登录、授权或送达。
